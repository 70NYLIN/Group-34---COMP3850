# Group 34 – COMP3850 Prototype

## Project Overview

This repository contains a frontend prototype for the Group 34 COMP3850 project.  
The prototype includes an interactive FAQ section and a multi-step Program Enquiry Form.

## Key Features

- Responsive page layout
- FAQ accordion section
- Multi-step enquiry form
- Basic form validation
- Enquiry receipt/confirmation summary
- Mobile-friendly styling
